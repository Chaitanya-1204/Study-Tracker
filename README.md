# Study Tracker

A simple study progress tracker. Organise what you're learning into topics,
subtopics and items, tick things off as you go, and watch the progress rings
fill up. Everything is saved in your browser — no account, no backend.

**[Open the app →](https://chaitanya-1204.github.io/Study-Tracker/)**

## Run locally

```bash
npm install
npm run dev
```
